# 自建翻墙 · 分阶段部署笔记

从商业 VPN（QuickQ 等）迁移到**自己完全掌控**的自建代理。
按"先跑通、再加码"的思路分成 4 个阶段，每个阶段都是上一阶段的稳定叠加，
你可以随时停在任意阶段，确认稳定后再进入下一阶段。

## 总体架构

```
你的设备(客户端) → 加密代理 → 你租的海外 VPS → 自由互联网
```

需要三样东西：**海外 VPS** + **服务端代理软件(Xray/Hysteria2)** + **本地客户端(Clash 等)**。

| 阶段 | 目标 | 加什么 | 文档 |
|------|------|--------|------|
| **P1 跑通** | 一台 VPS + 一个 Reality 节点，自己一台设备能翻 | 1 台 VPS、Xray Reality | [phase1-跑通.md](./phase1-跑通.md) |
| **P2 全家** | 链接发给十几台设备共用 / 面板管理 | 节点链接共享、3X-UI 面板 | [phase2-多设备.md](./phase2-多设备.md) |

## 预算与规模（本人情况）

- **设备规模**：本人多设备 + 家人，约十几个终端。
- **账号需求**：**给每个使用的人单独配一个账号**（独立链接、可单独看流量/禁用）→ 用 3X-UI 面板，见 [P2 路线 B](./phase2-多设备.md#路线-b3x-ui-面板每设备每家人独立账号精细管理)。
- **年预算**：¥1000–2000（实际单主力机约 ¥400–600/年，双节点约 ¥1100–1500/年，仍有余地）。
- **特殊需求**：去过新疆，普通商业 VPN 全灭 → 优先抗封锁强的协议（Reality / Hysteria2）。

## 协议选择速记

| 协议 | 抗封锁 | 备注 |
|------|--------|------|
| Shadowsocks（纯） | 弱 | 容易被识别，不推荐做主力 |
| **VLESS + Vision + Reality** | **强** | 伪装成正常 HTTPS，**不需要域名/证书**，主力首选 |
| **Hysteria2** | 强 | 基于 QUIC/UDP，弱网/被限速时速度好，做备用 |

## 安全底线（自建必做）

- SSH 改**密钥登录**，禁用 root 密码登录，改默认端口。
- 开防火墙（ufw / nftables），只放行必要端口。
- 定期 `apt update && apt upgrade`。
- 不要在仓库里提交真实的 UUID / 私钥 / 服务器 IP —— 配置文件均为**模板**，真实值填到服务器上即可。
