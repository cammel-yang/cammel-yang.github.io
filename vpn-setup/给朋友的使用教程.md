# 科学上网 · 使用教程（朋友版）

你会收到两样东西（向把这个发给你的人要）：
1. 一个**二维码**（手机扫）或一条 **`vless://...` 链接**（电脑用）。
2. 这份教程。

> 说明：链接 = 你的专属钥匙，**别转发给别人**。你最多能 **2 台设备同时**在线。

按你的设备，照对应那一节做即可。

---

## 📱 iPhone / iPad

### 1. 装客户端
中国区 App Store 搜不到翻墙 App，需要用**外区（如美区）Apple ID** 下载：
- 推荐 **Shadowrocket（小火箭）**，约 $2.99。
- 没有外区 ID：先注册一个美区 Apple ID（免费），切到美区 App Store 再下；或用免费的 **sing-box**（同样需外区 ID）。

### 2. 导入节点
1. 打开 Shadowrocket → 右上角 **➕**。
2. 选 **扫描二维码** → 对着对方发你的二维码扫一下，自动导入。
   - 没二维码、只有链接：复制链接 → 回到小火箭它会自动识别 → 添加。

### 3. 开启
1. **点一下**那个节点选中它。
2. 顶部 **全局路由** 选 **「配置」**（国内网站直连、国外才走代理，省流量）。
3. 打开最上面的**总开关** → 弹窗点 **允许** → 输密码/Face ID。
4. 手机顶部状态栏出现 **VPN** 字样即成功。

### 4. 验证
Safari 打开 google.com 能开就成了。

## 🤖 Android 手机

### 1. 装客户端
装 **v2rayNG** 或 **NekoBox**（从官方 GitHub 下 APK 安装，或应用商店搜）。

### 2. 导入节点
- 打开 App → 右上角 **+** → **扫描二维码** → 扫对方给的码。
- 或：复制链接 → **+** → **从剪贴板导入**。

### 3. 开启
1. 选中导入的节点。
2. 点右下角的 **连接按钮**（V 形图标）→ 弹窗点 **允许**。
3. 状态栏出现 **VPN** 钥匙图标即成功。

### 4. 验证
浏览器开 google.com。

## 💻 Windows / Mac 电脑

### 1. 装客户端
装 **Clash Verge**（Windows/Mac 都有，GitHub 搜 “Clash Verge Rev” 下载）。

### 2. 导入节点（用链接）
Clash 用配置文件，不能直接粘 `vless://` 链接，所以这样做：
1. Clash Verge → 左侧 **订阅(Profiles)** → **+** → 类型 **Local** → 起个名 → 创建。
2. 点它**编辑**，把对方发你的 **Clash 配置（YAML）** 整段粘进去 → 保存。
   - 如果对方只给了 `vless://` 链接，让他帮你把链接转成 Clash 配置（他那边一键能导出）。
3. **点这个配置让它生效**（高亮/打勾）。

### 3. 开启
1. 左侧 **设置** → 打开 **系统代理** 或 **虚拟网卡模式(Tun)** 开关。
   - Mac 第一次会让你输开机密码授权，输一次即可。
2. 左侧 **代理** → 选中那个节点。

### 4. 验证
浏览器开 google.com / youtube.com。

## 日常使用 & 注意

- **怎么关**：把客户端的总开关关掉即可，国内上网完全不受影响。
- **国内网站照常**：微信、淘宝、网银等走直连，不受代理影响、也不慢。
- **省流量**：用「配置/规则」模式，别用「全局」（全局会把国内流量也绕出去，费流量）。
- **2 台设备**：你最多 2 台同时在线；第 3 台连不上是正常的，关掉一台再连。
- **链接保密**：链接/二维码等于密码，别发到群里或给别人。
- **连不上时**：先关代理重开一次；还不行就把现象告诉发你链接的人（他能在后台查）。
