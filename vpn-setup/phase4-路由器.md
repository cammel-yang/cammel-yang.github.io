# P4 · 省心：家里路由器统一接管

前提：[P3](./phase3-冗余备份.md)（或至少 P2）已稳定。本阶段让**家里所有连 WiFi 的设备
自动翻墙**，家人（尤其老人、电视、平板）零操作、不用各自装客户端。

---

## 思路

在家里的路由器上跑代理客户端（OpenClash），由它统一判断哪些流量走代理、哪些直连。
设备只要连这个 WiFi 就自动生效。

```
家里设备(手机/电脑/电视/平板) → WiFi → 路由器(OpenClash) → 主力/备用节点 → 自由互联网
```

## 硬件选择（一次性支出）

| 选项 | 价格 | 说明 |
|------|------|------|
| 刷 OpenWrt 的软路由 / 支持的路由器 | ¥200–500 | 家用主力，性能足、稳定 |
| 旅行路由器（GL.iNet 等，自带固件） | ¥150–300 | 出门/酒店/旅游，一个小盒子全家一起翻 |

> 买前确认型号**支持 OpenWrt 且性能够**（建议 ≥256MB 内存，跑代理才不卡）。
> GL.iNet 系列出厂即带类 OpenWrt 固件，最省事，推荐新手。

## 配置步骤（概要）

1. 路由器刷/确认为 **OpenWrt** 固件（GL.iNet 出厂自带可跳过）。
2. 安装 **OpenClash** 插件。
3. 在 OpenClash 里导入订阅或手动添加 P1/P3 的节点（Reality + Hysteria2）。
4. 选择分流规则集（默认规则可区分国内外，国内直连、国外走代理）。
5. 启动 OpenClash → 家里设备连 WiFi 即自动翻墙。
6. 手机等要带出门的设备，仍单独装客户端（家里靠路由器，在外靠客户端）。

> 详细刷机/插件步骤因路由器型号差异较大，等你确定了具体型号，我再把这一节按你的机器写细。

## 本阶段完成标志
- 家里任意设备连上 WiFi，无需任何配置即可访问外网，国内站点不受影响（直连不绕路）。
