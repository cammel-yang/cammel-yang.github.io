# P3 · 冗余备份：第二台 VPS + Hysteria2

前提：[P2](./phase2-多设备.md) 已稳定。本阶段解决"单点失效"——
一台被封/抽风（尤其新疆等强管控环境）时，自动有另一条线路顶上。

核心思路：**两个不同厂商、不同机房、不同协议**的节点，互为备份。

---

## 为什么要不同厂商 + 不同协议

- 不同**厂商/机房** → IP 段不同，不容易被一起封。
- 不同**协议**（Reality 是 TCP 伪装 HTTPS，Hysteria2 是 QUIC/UDP）→ 当某一类流量被针对性封锁/限速时，另一类还能活。
- 新疆经验：单协议随时可能挂，双协议存活率明显更高。

## 第 1 步：再租一台 VPS

- 选**和主力不同的厂商/机房**（如主力 Vultr 东京，备用换 DigitalOcean 新加坡，或搬瓦工）。
- 最低配即可，备用机平时流量小。

## 第 2 步：在备用机上装 Hysteria2

官方一键脚本：

```bash
bash <(curl -fsSL https://get.hy2.sh/)
```

装完编辑服务端配置（参考本目录 `configs/hysteria2-server.yaml` 模板），
设置端口、密码、以及伪装用的 `masquerade` 站点，然后启动：

```bash
systemctl enable --now hysteria-server
```

把生成的 `hysteria2://...` 链接保存好。

> Hysteria2 走 UDP，注意 VPS 防火墙/安全组放行对应 **UDP 端口**。

## 第 3 步：客户端里把两个节点放一起

在 Clash Verge / v2rayN / NekoBox / 小火箭里：

1. 同时导入**主力 Reality** 和**备用 Hysteria2** 两条链接。
2. 建一个分组，把两个节点都放进去。
3. 模式选 **自动测速（url-test）** 或手动一键切换。
4. 主力挂了 → 手动/自动切到备用，体验基本无缝。

## 第 4 步：去新疆 / 敏感时期怎么用

- 出发前确认两个节点都能连。
- 到当地若主力 Reality 不通，切 Hysteria2 试；都不通则错峰再试。
- 重要资料/地图/翻译**提前下离线版**，别完全指望现场翻。

## 本阶段完成标志
- 两条不同厂商 + 不同协议的线路都可用，客户端里能一键/自动切换。
