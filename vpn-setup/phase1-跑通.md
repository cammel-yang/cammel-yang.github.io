# P1 · 跑通：一台 VPS + Reality 节点

目标：**最小可用**。一台海外 VPS，部署一个 VLESS+Vision+Reality 节点，
让你自己的一台设备（手机或电脑）能稳定翻墙。先验证链路，别管多设备和备份。

预计耗时：30–60 分钟。

---

## 第 1 步：租一台 VPS（已选定方案）

**最终方案：搬瓦工（BandwagonHost）洛杉矶 CN2 GIA，大流量档。**
理由：**美国 IP**（用途见下）+ **CN2 GIA 对华线路**晚高峰也稳（看 YouTube 不卡）+
独享固定 IP（利于保 Claude 账号）。

为什么是这套（本人需求）：
- **要美国 IP**：主要为保护 Claude 账号 —— 独享、固定、支持地区的 IP 风控风险最低（详见文末「保号注意事项」）。
- **看 YouTube 不卡**：靠的是带宽 + 对华优化线路，CN2 GIA 正好满足；普通公网线路晚高峰会卡，不选。
- **全家十几台**：选**大流量档**（看视频很费流量，1080p 约 1.5GB/小时、4K 约 7GB/小时）。

购买步骤：

1. 打开搬瓦工 https://bandwagonhost.com/ ，注册账号。
2. 选套餐：找 **DC6 / DC9（洛杉矶 CN2 GIA-E）** 线路、**流量较大**的那一档（月流量 1TB 以上更稳妥）。
3. **机房（Location）**：务必选含 `Los Angeles ... CN2 GIA` 字样的，别选普通 `Direct`/默认线路。
4. **系统（OS）**：Debian 12 x64。
5. 付款（支持支付宝/银联/PayPal），**建议年付**（比月付便宜）。
6. 开通后在控制台记下：**服务器 IP**、**SSH 端口**、**root 密码**。

> 备注：搬瓦工同一套餐支持在后台 **Migrate（迁移机房）**，万一某个洛杉矶 IP 被封，可在后台切换到另一个 GIA 机房换 IP，很方便。
> 备用节点（不同厂商/协议）留到 [P3](./phase3-冗余备份.md) 再加。

## 第 2 步：登录服务器并加固（基础）

本机终端执行（把 `SERVER_IP` 换成你的 IP）：

```bash
ssh root@SERVER_IP
```

进去后先更新系统：

```bash
apt update && apt upgrade -y
```

> SSH 密钥登录、改端口等更完整的加固见 README「安全底线」。P1 先跑通，加固可稍后补。

## 第 3 步：一键安装 Xray（Reality）

社区维护的 233boy 脚本，菜单式操作，自动生成节点链接：

```bash
bash <(curl -L https://github.com/233boy/Xray/raw/main/install.sh)
```

安装时：

1. 协议选 **VLESS**（或直接选带 `Reality` 的项）。
2. 回车使用默认端口 / 默认偷取的域名（脚本会自动选一个常见大站如 `www.microsoft.com` 做伪装）。
3. 装完脚本会直接打印一条 **`vless://...` 节点链接**和二维码 —— 复制保存好。

> 想手动理解配置结构，可参考本目录 `configs/xray-reality-server.json` 模板
> （真实的 UUID、私钥由脚本自动生成，不要手填）。

常用管理命令：

```bash
v2ray          # 打开管理菜单（查看/修改/重启）
v2ray info     # 再次查看节点链接和二维码
```

## 第 4 步：本地客户端导入

挑一个客户端，把上面的 `vless://...` 链接导入：

| 平台 | 客户端 | 导入方式 |
|------|--------|----------|
| Windows | v2rayN / Nekoray / Clash Verge | 从剪贴板导入 |
| macOS | Clash Verge / ClashX Meta | 从剪贴板导入 |
| Android | v2rayNG / NekoBox | 扫码或粘贴链接 |
| iOS | Shadowrocket（小火箭，需外区 App Store） | 扫码或粘贴 |

导入后：选中该节点 → 开启代理（系统代理 / Tun 模式）。

## 第 5 步：验证

1. 浏览器访问一个被墙的网站（如 google.com）能打开。
2. 搜索"my ip"，确认显示的是你 VPS 的 IP / 所在国家。
3. 在客户端里看延迟（ping）：东京线路一般几十到一百多毫秒算正常。

✅ 都通过 = P1 完成，你已经有了一个完全自己掌控的节点。

## 常见问题

- **连不上 / 一直转圈**：
  - 确认客户端开了"系统代理"或"Tun 模式"。
  - 确认 VPS 防火墙放行了节点端口（Vultr 默认全放，问题不大）。
  - 换个端口或重新生成节点（`v2ray` 菜单里操作）。
- **能连但很慢**：换机房（东京/新加坡/美西多试），或升级带宽套餐。
- **用一阵突然全挂**：可能 IP 被封 → Vultr 上销毁实例、重建一台新 IP，重跑第 3 步。这也是 P3 要加备用节点的原因。

## 保号注意事项（保护 Claude 等账号）

自建的最大好处之一就是**独享 + 固定 IP**，比 QuickQ 那种共享/乱跳的 IP 安全得多。
为最大化降低封号风险：

- **固定用这一台 VPS 登 Claude**，别再用共享商业 VPN（共享 IP 容易被别人连累标记）。
- **一个账号长期固定一个国家的 IP**，别一会儿美国一会儿日本地切 —— 登录地稳定最重要。
- 让 Claude 等重要账号**只走主力节点**，不要随备用节点频繁跳。
- 尽量别在短时间内「中国直连 ↔ 翻墙」反复横跳。
- 美国/日本都是 Claude 支持地区，本方案用美国 IP；中国大陆/香港不在支持名单，所以必须翻出去用。

> 说明：从不支持地区用 VPN 访问属于服务条款灰色地带，无法 100% 杜绝风险；
> 但「独享 + 固定 IP + 不乱跳」已是普通用户能做到的最稳妥方式。
